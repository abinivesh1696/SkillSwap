# SkillSwap Hub

A polished frontend demo application for learning exchange and skill sharing between students. Built with React, Vite, and Bootstrap 5, SkillSwap Hub showcases a modern responsive interface with search, filtering, profile browsing, and swap request handling.

## 🚀 Project Overview

SkillSwap Hub is designed to help students discover peers with complementary skills and request skill swaps in a user-friendly interface. The application focuses on:

- Browsing student profiles with expertise and availability
- Filtering and searching by skill categories
- Sending and managing swap requests
- Storing favorites and requests locally for a seamless demo experience
- Presenting a responsive layout with a modern glassmorphism-inspired UI

## 🧩 Key Features

- Explore curated student profiles
- Search and filter by category or keyword
- Favorite profiles with localStorage persistence
- Create and manage swap requests
- Responsive UI with dark mode and Bootstrap styling
- Built as a frontend-only React application

## 🛠️ Tech Stack

- React 18
- Vite
- Bootstrap 5
- React Router DOM
- React Icons
- React Toastify

## 📁 Project Structure

- `src/`
  - `App.jsx` — main app layout and routing
  - `main.jsx` — React application entry point
  - `components/` — reusable UI components
  - `constants/` — app constants and static data
  - `context/` — authentication and app state context
  - `data/` — sample student profile data
  - `pages/` — route views (Home, Explore, Dashboard, etc.)
  - `styles/` — custom CSS for layout and styling

## ▶️ Getting Started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal to view the application.

## ✅ Available Scripts

- `npm run dev` — start development server
- `npm run build` — create production build
- `npm run preview` — preview the production build locally

## 💡 Notes

This project is currently a frontend-only demo and uses browser storage for persistent state. It is ideal for prototyping UI flows and demonstrating student skill exchange interactions.
